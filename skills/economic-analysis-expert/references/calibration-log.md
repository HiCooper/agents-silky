# 判断校准日志（Calibration Log）

> **用途**：落地《经济分析专家身份文档》第 9 节「自我进化机制」——记录每次重要判断的
> 「判断 + 置信度 + 证伪条件 + 日期」，事后对照实际结果，计算**命中率与校准度**，
> 归因错误类型，并据此调整工具箱/因子的权重。
>
> **写入规则（两层，2026-09-15 起）**：
> - **原始层 = 项目内**：项目根目录的 `calibration-log.md`。日频写入每条可检验判断的完整记录（含点位、个股、资金流等一次性细节），写完即止，**不改本文件**。
> - **提炼层 = 本文件**：只收录**换标的 / 换项目 / 换月份仍成立**的教训——新增或废弃的因子、阈值修正、失效边界、工具化方法。触发条件：同一模式重复 ≥2–3 次，或某个框架被证伪。
> - 判据：「这条结论换一个项目、换一个月还成立吗？」成立 → 写入本文件；只是当天细节 → 留在项目文件。
>
> **归因分类**：`模型老化`（框架失效边界被触发） / `参数更新`（数值/阈值过时） / `执行误判`（分析或操作偏差）。

### 2026-09-14（周一）——韩国因子首个实盘检验日

**判断与结果逐条对照：**

| 时点 | 判断 | 实际 | 评分 |
|---|---|---|---|
| 08:35 盘前 | 「修复式反弹，但仍是深调格局」，建议冲高减仓 | 高开未兑现，全天低开走弱 | ❌ 方向偏乐观 |
| 08:50 读到韩国后 | 下调为「A股科技**低开概率高**」 | 低开、科技杀跌 | ✅ 命中 |
| 10:15 盘中 | 「指数横、科技弱势主体」；基准磨底55% / 反抽25% / 深调20% | 上证 −0.07%（横）✅、科创50 −1.62%（弱）✅ | ⚠️ 部分命中 |
| 10:15 盘中 | 「半导体ETF 0.935 是底线」 | 最低 0.935、收 0.947，守住 | ✅ 命中 |
| 10:15 盘中 | 「韩国在修复」→ 当作 A股科技企稳的边际利好 | 韩国收在近全天最低，**KOSPI −3.26%** | ❌ **关键误判** |

**实际结果（收盘）**：上证 3885.33 −0.07%、创业板 −1.10%、科创50 1528.27 −1.62%、半导体ETF −1.35%（最低 0.935）、芯片ETF −1.74%；防御性调整，医疗服务走强；港股逆势收红（HSI +0.45%）。盘后：纳指期货 −1.81%、黄金 −2%、美元指数 99.55。

**归因：**
1. **执行误判（主因）**：把韩国 10:00 的盘中反弹（−2.88%→−2.17%）**当成企稳确认**——问题不在「看了盘中」，而在**用一个跳动覆盖了当时正在走弱的外部趋势**（纳指期货、美元、黄金）。教训：盘中信号要**标为暂定、按权重融入、并持续更新**，而非禁止使用或锁死时点。
2. **执行误判**：低估了「外部变量全天趋势」的权重——纳指期货从 −1.07% 恶化到 −1.81%、黄金转跌、美元走强，趋势向下时，单一市场盘中反弹不构成反转。
3. **执行误判**：未用上「南下资金连续 10 日净卖出中芯国际」这条 A/H 结构性分化信号。
4. **参数/权重**：在已确认的鹰派 regime（10Y 4.97%、加息概率 ~90%）下仍给「反抽」25% 权重，先验偏中性。

**改进（已落地）：**
- 《早盘跨市场前瞻因子》新增：**任何时点可按当下信息尽力判断、持续更新**、**趋势 > 跳动**、**regime 决定先验**。
- 观察清单新增第 8 项：**恒生科技 + 南下资金对 A+H 半导体的连续净买卖**。
- 结论：**regime 是敌意时，情景概率必须向「走弱/深调」倾斜**，不再沿用中性分布。

### 2026-09-15（周二）——「AI 硬件第二次定价」（提炼）

> 原始记录（当日点位、个股、资金流、三情景全文）在**项目内** `calibration-log.md`；此处只留可复用部分。

**提炼 1｜跨市场传导要有量化锚，不能凭感觉等同幅度。** 新工具：用 akshare 新浪源费半 `.SOX` 日线对齐科创50 / 半导体ETF 的**次日**收益（672 个交易日，2023-10-31 ~ 2026-09-11）——相关系数仅 **0.119**、β = **0.111**（半导体ETF β = 0.13）。**费半单日 ≤ −5% 的 19 次样本**：科创50 次日均值 −1.10%、上涨占比 42%、**平均跳空仅 −0.53%（中位 −0.12%），但开盘→收盘再跌 −1.02%（中位 −0.95%）**。形态结论：**A 股不一步跌到位，是「低开不多、盘中阴跌」**，真正的杀跌多在 10:30–14:00。反直觉补充：**费半 5 日累计 ≤ −8% 时次日反而中性偏多**（n = 35，中位 +0.17%）——「单日重击」与「连续崩塌」的次日行为不同，先分清是哪一种。已写入 `premarket-korea-factor.md` §4。

**提炼 2｜「硬件→应用」换防应作为独立验证维度。** 本次费半 −5.2% 与纳指仅 −0.8%、道指 −0.2% 并存，同一时点微软 / 谷歌 / Meta / ServiceNow 逆势上涨；港股智谱 −9.08% 对腾讯 +0.51%、小米 +3.03%；A 股软件ETF +0.60% 对通信ETF −2.67%。**当硬件端与应用端方向相反时，「AI 叙事崩塌」的读法应立即降级为「风格换防」**——指数 β 被应用端对冲，这正是「费半暴跌而上证只跌 0.07%」的原因。检查清单相应新增：**同时读硬件链、应用链、指数三者方向**。

**提炼 3｜「口头倡议」类利空有明确的定价时滞，但不可反向看多。** 催化（9-12 三家 AI 公司齐声呼吁放缓，无订单或资本开支实证）先打亚太（9-14 KOSPI −3.26%、三星 −4.05%），**美股现金盘是最后一站**，A 股次日面对的是同一利空的**第二次定价**——应按「情绪二次释放 + 破位技术止损」定价，而非「基本面重估」。但也不能因此看多：**估值杀的幅度由持仓结构决定，不由基本面决定**；「基本面没坏」只是深跌之后值得分批的前提，且需先见止跌信号。

**提炼 4｜跨市场因子不单列，只当权重项（2026-09-15 定型）。** 早盘分析把韩国因子写成「独立小节 / 独立结论」是错的：它把一个**只对半导体 / 算力有效的同因子读数**抬成了方向锚，既违反「拒绝单一锚」，也会让读者误以为 A 股方向由韩国决定。改为**融进幅度与概率的论证**——韩国只负责回答「硬件链的开盘偏向要不要收窄 / 放大」，方向仍由美债实际利率、政策、资金三主轴与指数自身技术位决定。已改写 `premarket-korea-factor.md` §7（含正反写法对照）与 SKILL.md §5。

**提炼 5｜量化锚不是结论，锚与跨市场腿冲突时要被覆盖（2026-09-15 回填后定案）。** 9-15 的锚读数其实是对的——SOX ≤ −5% 时科创50 跳空中位 −0.12%，实际跳空 **−0.26%**；错的是我**用手工悲观把区间放大到 −1%~−2%**，并照搬锚的「盘内再跌 −0.95%」，而当天韩国翻红、纳指期货转正、A50 持平，外部趋势反向。结果科创50 收 **+1.55%**、半导体ETF **+1.80%**，「硬件补跌」被自己的证伪条件①正式否掉。**两条硬规则**：① 锚与跨腿冲突 → **以当下定价覆盖锚**，并把冲突写成结论，**不得取更悲观的那个**；② **失效边界被触发要在情景表里单列一格**（当天正确的情景是「海外链杀、A 股国产链独立走强」——康宁 −13.7%/Coherent −12.7% 只传导到光模块 −1%，寒武纪 +3.44%、中芯 +0.69%、PCB 涨停潮）。已写入 `premarket-korea-factor.md` §4/§5。

**9-15 检验结果（已回填项目内原始层，评分 ❌ 未命中）**：(a) 「指数抗跌」✅（上证 −0.54%）但「硬件补跌」❌（PCB/半导体涨停潮、科创50 +1.55%）；(b) 「低开不多」✅（−0.26%）但「盘中阴跌」❌（盘中 +1.81%）——**β 锚的跳空部分有效、盘内漂移部分在外部趋势反向时失效**；(c) 「硬件→应用」换防 ❌，应用端全跌，真实切换在**硬件内部：海外算力链 → 国产算力链 + PCB/材料**。

### 2026-09-16 ~ 09-17——「规则已在文档里却未执行」型失败（提炼）

> 触发条件满足：同一模式重复 4 次。原始记录在项目内 `calibration-log.md`；本节只留跨项目可复用部分。
> 评审时点：2026-09-17 13:45（覆盖 9-14 ~ 9-17 盘前的 14 条已评分判断）。

**提炼 6｜判断命中率高度不均：方向可预测，幅度与结构不可预测。** 14 条已评分判断分四类——**方向/形态** 5 条（✅3 ⚠️1 ❌1，70%）、**幅度区间** 2 条（❌2，**0%**）、**结构/风格** 3 条（✅0 ⚠️1 ❌2，**0 命中**）、**持续性/次日** 3 条（✅2 ⚠️1）。两条硬推论：① 情景表**不要再给虚假精确的点位区间**，只给方向 + 关键位（压力/支撑），幅度表述降级为「小/中/大」；② **风格轮动与相对强弱不得作为操作触发条件**——改用价格触发（破 X 减 Y / 站上 Z 加 W），因为结构判断的命中率支撑不起决策。这条同时解释了用户反复收到「少操作、多观察」的结构成因。

**提炼 7｜最高频且最贵的失败模式：规则/锚已在文档里，写结论时被叙事覆盖（4 次）。** ① 9-14 用韩国 10:00 的盘中反弹覆盖当时正在走弱的外部趋势（文档早写「趋势 > 跳动」）；② 9-15 用手工悲观把自己算出的跳空锚 −0.12% 放大到 −1%~−2%（实际 −0.26%）；③ 9-15 引用了「A 股含国产替代独立逻辑」这条失效边界却不给它任何权重；④ 9-17 读到「鹰派 regime 下情景概率须向走弱倾斜」的明文规则，仍给建设性情景 60%。**四次都不是分析能力不足，而是纪律缺失——正确答案已经在自己的笔记里，被当天叙事挤掉了。** 硬规则：**写情景与概率之前，先输出「证据清单」**——把已记录的规则、量化锚、整体性信号列成表，逐条标「支持 / 反对 / 中性」；清单完成前不得写概率分布；任何与清单冲突的结论必须显式写出冲突与覆盖理由。

**提炼 8｜同一条证据不得服务两个相反结论。** 两融 9-16 单日 +91.8 亿：9-16 收盘把它作为「反弹缺杠杆增量、存量博弈」的证据，9-17 盘前又把它作为「内部增量资金回归、支撑科技高开」的证据——同一数据、同一周期、相反用途，且未说明阈值规则变化。**这正是提炼 7 的放大器：先有叙事，再回头找证据。** 硬规则：每条证据写入时必须**绑定方向与阈值**；要反向使用，必须显式声明「阈值已变，原因是 X」。

**提炼 9｜整体性信号不得降级为局部信号。** 9-17 盘前把 A50 夜盘 −0.32% 解读为「压制大盘蓝筹」，理由是「成分偏金融/消费、与纳指期货不同源」，于是把**最直接的 A 股整体代理**降级成了风格证据，方向判断随之失败（实际低开小跌、毫无分化）。硬规则：**A50 夜盘 = A 股整体定价，属整体信号**；不得以「成分不同源」为由改判为局部/风格信号。同理适用于恒生科技、费半这类整体代理。

**提炼 10｜触发条件不配「默认动作条款」，等于把「等」当结论。** 9-16/9-17 的证伪条件设在 1693.48（距当时 +4.7%）、1647.53 等远端位，日常根本不会触发；结构性判断（换腿）则**完全没有价格触发**。结果是每天都能输出「观察」而不必做决定。硬规则：**每条判断必须写「默认动作条款」——若 N 个交易日内证伪条件未触发、也未反向触发，默认动作是什么（减 X / 加 X / 不动）**，N 与动作都要具体到标的与比例。

**提炼 11｜推算口径只能给区间，不能当定性结论。** 9-17 午间用「半日占全天 66%」外推得 18,857 亿，据此判断「放量不涨 → 滞涨换手」；而同日 13:43 的读数（14,377.4 亿 / 本表占比 0.806）反推半日系数应约 **0.70**，对应全天 ~17,780 亿——**低于 9-16 的 18,408 亿，实为缩量**。6% 的口径误差足以翻转「放量/缩量」这个**定性**结论。已落地：`akshare-data/fetch.py` 的 `_CUM_SHARE` 半日系数 0.66 → 0.70，并把 `fetch turnover` 的点估计改为**区间 + 不确定度提示**。硬规则：**凡定性结论（放量/缩量、强/弱）不得单独建立在推算值上，必须等收盘官方口径**。

**提炼 12｜回填是强制项，不靠记性。** 9-16 收盘的「本轮判断（待 9-17 回填）」5 条从未被系统回填——9-17 的两节直接新开判断跳过了上一轮，而跳过的正好包括后来被证伪的那条（「反弹缺杠杆增量」）。硬规则：**新一节的第一步必须是「回填上一轮所有未回填的判断」**，模板首行固定为回填表；上一轮没回填完，不得写新判断。已写入 `SKILL.md` §7。
