# 判断校准日志（Calibration Log）

> **用途**：落地《经济分析专家身份文档》第 9 节「自我进化机制」——记录每次重要判断的
> 「判断 + 置信度 + 证伪条件 + 日期」，事后对照实际结果，计算**命中率与校准度**，
> 归因错误类型，并据此调整工具箱/因子的权重。
>
> **写入规则**：每次盘前 / 盘中 / 收盘给出可检验的判断后，追加一条记录；收盘或次日回填「实际结果」与「归因」。
>
> **归因分类**：`模型老化`（框架失效边界被触发） / `参数更新`（数值/阈值过时） / `执行误判`（分析或操作偏差）。

---

## 模板

```
### YYYY-MM-DD（周X）
- **判断**（时点）：……（含方向与幅度预期）
- **置信度**：高 / 中 / 低
- **证伪条件**：若 X 发生，则判断错
- **实际结果**：……
- **评分**：✅ 命中 / ⚠️ 部分命中 / ❌ 未命中
- **归因**：模型老化 / 参数更新 / 执行误判
- **改进**：……（写入对应因子文档或调整权重）
```

### 2026-09-14（周一）——韩国因子首个实盘检验日

**判断与结果逐条对照：**

| 时点 | 判断 | 实际 | 评分 |
|---|---|---|---|
| 08:35 盘前 | 「修复式反弹，但仍是深调格局」，建议冲高减仓 | 高开未兑现，全天低开走弱 | ❌ 方向偏乐观 |
| 08:50 读到韩国后 | 下调为「A股科技**低开概率高**」 | 低开、科技杀跌 | ✅ 命中 |
| 10:15 盘中 | 「指数横、科技弱势主体」；基准磨底55% / 反抽25% / 深调20% | 上证 −0.07%（横）✅、科创50 −1.62%（弱）✅ | ⚠️ 部分命中 |
| 10:15 盘中 | 「半导体ETF 0.935 是底线」 | 最低 0.935、收 0.947，守住 | ✅ 命中 |
| 10:15 盘中 | 「韩国在修复」→ 当作 A股科技企稳的边际利好 | 韩国收在近全天最低，**KOSPI −3.26%** | ❌ **关键误判** |

**实际结果（收盘）**：上证 3885.33 −0.07%、创业板 −1.10%、科创50 1528.27 −1.62%、半导体ETF −1.35%（最低 0.935）、芯片ETF −1.74%；防御性调整，医疗服务走强；港股逆势收红（HSI +0.45%）。盘后：纳指期货 −1.81%、黄金 −2%、美元指数 99.55。

**归因：**
1. **执行误判（主因）**：把韩国 10:00 的盘中反弹（−2.88%→−2.17%）**当成企稳确认**——问题不在「看了盘中」，而在**用一个跳动覆盖了当时正在走弱的外部趋势**（纳指期货、美元、黄金）。教训：盘中信号要**标为暂定、按权重融入、并持续更新**，而非禁止使用或锁死时点。
2. **执行误判**：低估了「外部变量全天趋势」的权重——纳指期货从 −1.07% 恶化到 −1.81%、黄金转跌、美元走强，趋势向下时，单一市场盘中反弹不构成反转。
3. **执行误判**：未用上「南下资金连续 10 日净卖出中芯国际」这条 A/H 结构性分化信号。
4. **参数/权重**：在已确认的鹰派 regime（10Y 4.97%、加息概率 ~90%）下仍给「反抽」25% 权重，先验偏中性。

**改进（已落地）：**
- 《早盘跨市场前瞻因子》新增：**任何时点可按当下信息尽力判断、持续更新**、**趋势 > 跳动**、**regime 决定先验**。
- 观察清单新增第 8 项：**恒生科技 + 南下资金对 A+H 半导体的连续净买卖**。
- 结论：**regime 是敌意时，情景概率必须向「走弱/深调」倾斜**，不再沿用中性分布。
