# 判断校准日志（Calibration Log）

> **用途**：落地《经济分析专家身份文档》第 9 节「自我进化机制」——记录每次重要判断的
> 「判断 + 置信度 + 证伪条件 + 日期」，事后对照实际结果，计算**命中率与校准度**，
> 归因错误类型，并据此调整工具箱/因子的权重。
>
> **写入规则（两层，2026-09-15 起）**：
> - **原始层 = 项目内**：项目根目录的 `calibration-log.md`。日频写入每条可检验判断的完整记录（含点位、个股、资金流等一次性细节），写完即止，**不改本文件**。
> - **提炼层 = 本文件**：只收录**换标的 / 换项目 / 换月份仍成立**的教训——新增或废弃的因子、阈值修正、失效边界、工具化方法。触发条件：同一模式重复 ≥2–3 次，或某个框架被证伪。
> - 判据：「这条结论换一个项目、换一个月还成立吗？」成立 → 写入本文件；只是当天细节 → 留在项目文件。
>
> **归因分类**：`模型老化`（框架失效边界被触发） / `参数更新`（数值/阈值过时） / `执行误判`（分析或操作偏差）。

### 2026-09-14（周一）——韩国因子首个实盘检验日

**判断与结果逐条对照：**

| 时点 | 判断 | 实际 | 评分 |
|---|---|---|---|
| 08:35 盘前 | 「修复式反弹，但仍是深调格局」，建议冲高减仓 | 高开未兑现，全天低开走弱 | ❌ 方向偏乐观 |
| 08:50 读到韩国后 | 下调为「A股科技**低开概率高**」 | 低开、科技杀跌 | ✅ 命中 |
| 10:15 盘中 | 「指数横、科技弱势主体」；基准磨底55% / 反抽25% / 深调20% | 上证 −0.07%（横）✅、科创50 −1.62%（弱）✅ | ⚠️ 部分命中 |
| 10:15 盘中 | 「半导体ETF 0.935 是底线」 | 最低 0.935、收 0.947，守住 | ✅ 命中 |
| 10:15 盘中 | 「韩国在修复」→ 当作 A股科技企稳的边际利好 | 韩国收在近全天最低，**KOSPI −3.26%** | ❌ **关键误判** |

**实际结果（收盘）**：上证 3885.33 −0.07%、创业板 −1.10%、科创50 1528.27 −1.62%、半导体ETF −1.35%（最低 0.935）、芯片ETF −1.74%；防御性调整，医疗服务走强；港股逆势收红（HSI +0.45%）。盘后：纳指期货 −1.81%、黄金 −2%、美元指数 99.55。

**归因：**
1. **执行误判（主因）**：把韩国 10:00 的盘中反弹（−2.88%→−2.17%）**当成企稳确认**——问题不在「看了盘中」，而在**用一个跳动覆盖了当时正在走弱的外部趋势**（纳指期货、美元、黄金）。教训：盘中信号要**标为暂定、按权重融入、并持续更新**，而非禁止使用或锁死时点。
2. **执行误判**：低估了「外部变量全天趋势」的权重——纳指期货从 −1.07% 恶化到 −1.81%、黄金转跌、美元走强，趋势向下时，单一市场盘中反弹不构成反转。
3. **执行误判**：未用上「南下资金连续 10 日净卖出中芯国际」这条 A/H 结构性分化信号。
4. **参数/权重**：在已确认的鹰派 regime（10Y 4.97%、加息概率 ~90%）下仍给「反抽」25% 权重，先验偏中性。

**改进（已落地）：**
- 《早盘跨市场前瞻因子》新增：**任何时点可按当下信息尽力判断、持续更新**、**趋势 > 跳动**、**regime 决定先验**。
- 观察清单新增第 8 项：**恒生科技 + 南下资金对 A+H 半导体的连续净买卖**。
- 结论：**regime 是敌意时，情景概率必须向「走弱/深调」倾斜**，不再沿用中性分布。

### 2026-09-15（周二）——「AI 硬件第二次定价」（提炼）

> 原始记录（当日点位、个股、资金流、三情景全文）在**项目内** `calibration-log.md`；此处只留可复用部分。

**提炼 1｜跨市场传导要有量化锚，不能凭感觉等同幅度。** 新工具：用 akshare 新浪源费半 `.SOX` 日线对齐科创50 / 半导体ETF 的**次日**收益（672 个交易日，2023-10-31 ~ 2026-09-11）——相关系数仅 **0.119**、β = **0.111**（半导体ETF β = 0.13）。**费半单日 ≤ −5% 的 19 次样本**：科创50 次日均值 −1.10%、上涨占比 42%、**平均跳空仅 −0.53%（中位 −0.12%），但开盘→收盘再跌 −1.02%（中位 −0.95%）**。形态结论：**A 股不一步跌到位，是「低开不多、盘中阴跌」**，真正的杀跌多在 10:30–14:00。反直觉补充：**费半 5 日累计 ≤ −8% 时次日反而中性偏多**（n = 35，中位 +0.17%）——「单日重击」与「连续崩塌」的次日行为不同，先分清是哪一种。已写入 `premarket-korea-factor.md` §4。

**提炼 2｜「硬件→应用」换防应作为独立验证维度。** 本次费半 −5.2% 与纳指仅 −0.8%、道指 −0.2% 并存，同一时点微软 / 谷歌 / Meta / ServiceNow 逆势上涨；港股智谱 −9.08% 对腾讯 +0.51%、小米 +3.03%；A 股软件ETF +0.60% 对通信ETF −2.67%。**当硬件端与应用端方向相反时，「AI 叙事崩塌」的读法应立即降级为「风格换防」**——指数 β 被应用端对冲，这正是「费半暴跌而上证只跌 0.07%」的原因。检查清单相应新增：**同时读硬件链、应用链、指数三者方向**。

**提炼 3｜「口头倡议」类利空有明确的定价时滞，但不可反向看多。** 催化（9-12 三家 AI 公司齐声呼吁放缓，无订单或资本开支实证）先打亚太（9-14 KOSPI −3.26%、三星 −4.05%），**美股现金盘是最后一站**，A 股次日面对的是同一利空的**第二次定价**——应按「情绪二次释放 + 破位技术止损」定价，而非「基本面重估」。但也不能因此看多：**估值杀的幅度由持仓结构决定，不由基本面决定**；「基本面没坏」只是深跌之后值得分批的前提，且需先见止跌信号。

**提炼 4｜跨市场因子不单列，只当权重项（2026-09-15 定型）。** 早盘分析把韩国因子写成「独立小节 / 独立结论」是错的：它把一个**只对半导体 / 算力有效的同因子读数**抬成了方向锚，既违反「拒绝单一锚」，也会让读者误以为 A 股方向由韩国决定。改为**融进幅度与概率的论证**——韩国只负责回答「硬件链的开盘偏向要不要收窄 / 放大」，方向仍由美债实际利率、政策、资金三主轴与指数自身技术位决定。已改写 `premarket-korea-factor.md` §7（含正反写法对照）与 SKILL.md §5。

**待回填（回填到项目内原始层）**：9-15 收盘后填实际结果、评分、归因。重点检验 (a) 「指数抗跌 + 硬件补跌」的结构；(b) 是否出现「低开不多、盘中阴跌」形态——若开盘即最低、全天单边上行，说明 β 型锚失效，需回炉；(c) 「硬件→应用」换防在 A 股是否被验证（软件ETF / 计算机ETF 相对收益）。
