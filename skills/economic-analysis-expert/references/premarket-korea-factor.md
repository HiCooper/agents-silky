# 早盘跨市场前瞻因子：韩国股市（KOSPI / KOSDAQ）

> **用途**：A股早盘分析（09:30 开盘前）的前瞻性输入因子。
> **适用时机**：每个交易日 08:00–09:30（北京时间）——韩国已开盘、A股与A股期货尚未开盘。
> **一句话**：韩国早盘是 A 股**半导体/算力当日开盘方向**的第一顺位跨市场指标；但它只对「同一驱动因子」的板块有效，**不能机械外推到整个上证/沪深300**。
> **首次纳入**：2026-09-14（因当日韩国对 A 股的强前瞻信号而把该因子制度化）。

---

## 1. 为什么韩国早盘对 A 股有参考价值（三个机制）

1. **时间领先**：韩国 08:00（北京时间，KST−1h）开盘，A股 09:30 开盘，**领先约 1.5 小时**；同属亚太时段，共享同一批隔夜宏观变量（美债、美元、油价、美股期货）。
2. **结构重叠**：KOSPI 由**存储/半导体**主导（三星电子、SK海力士），与 A 股的半导体、存储、算力硬件处在**同一个全球芯片周期**上。费半（SOX）之外，韩国是**离 A 股开盘最近的「芯片 beta」读数**。
3. **资金属性**：韩国是外资主导市场，外资在韩的买卖是**亚洲科技风险偏好的先行读数**，可映射 A 股科技情绪与北向资金。

---

## 2. 何时最有用 / 何时是噪音

| 情形 | 信号价值 | 处理方式 |
|---|---|---|
| **亚洲早盘与美股收盘背离**（如美股涨、韩国跌） | **最高** | 亚洲在定价美股尚未反映的**新风险**（地缘、AI 叙事、区域消息），**以韩国/期货为准** |
| 宏观驱动日（美债、加息预期、油价主导） | 高 | 韩国与纳指期货**同向**时信号最硬 |
| A股有独立政策催化（国内稳增长、产业政策） | 低 | 韩国只影响开盘情绪，盘中由国内政策主导 |
| 韩国单一公司/事件驱动的下跌 | 低 | 剔除个股因素，看板块整体（三星+海力士是否同跌） |

## 3. 观察清单（08:00–09:30 逐项核对）

1. **KOSPI 指数**涨跌幅 + 是否跳空低开/高开；
2. **KOSDAQ**（成长/科技）涨跌幅；
3. **三星电子（005930）**、**SK海力士（000660）**——存储双雄是否**同向**（同向=板块性，单边=个股性）；
4. **外资/机构净买卖**方向（韩媒盘中会报「외국인 매도」即外资卖出）；
5. **亚洲对照**：日经、台股（若可取）是否同向；
6. **美股期货**：纳指期货（NQ）优先于标普期货（ES），科技属性更强；
7. **共同宏观**：10Y 美债、美元指数、油价、黄金（判断是「科技自身」还是「宏观驱动」）；
8. **恒生科技（HSTECH）+ 南下资金**：港股 AI/科技强弱、南下资金对**中芯国际等 A+H 半导体**的连续净买卖。**若南下连续净卖出 A 股半导体、同时净买入港股 AI，说明资金在「弃 A 半导体、买 H AI」——这是 A 股半导体的结构性逆风，港股的强不能对冲。**

数据取得：新浪 `hq.sinajs.cn`（`znb_KOSPI`、`znb_KOSDAQ`、`hf_ES`、`hf_NQ`、`DINIW`、`hf_CL`、`hf_GC`）；韩国个股若取不到实时价，用韩媒快讯确认涨跌幅方向。
**KOSPI 历史日线**（2026-09-15 新增，用于把「韩国 vs A 股科技」从当天方向读数升级为可量化对比）：`ak.index_global_hist_sina(symbol="首尔综合指数")`——新浪源、约 1000 条、稳定；东财 `index_global_hist_em` 走 push2his 会被本机代理间歇拦截，只作兜底。**KOSDAQ 无历史接口**，只有实时值。有了 KOSPI 历史 + 科创50 历史，就能算「相对强弱（起点归一）」并识别背离，而不只是看早盘 1.5 小时的跳动。

## 4. 判定规则（与现有阈值对齐）

- **三方共振**（韩国芯片 + 纳指期货 + 费半 **同向**）→ 信号强度高，可作为 A 股半导体/算力**开盘方向**的判断依据。
- **背离** → 以**韩国 / 美股期货**为准（它们是**当下定价**）；美股现金收盘是**过去时**。
- **开盘偏向映射**：韩国芯片大跌 → A 股半导体/算力/科创50 **低开概率高**；反之亦然。
- **幅度不要机械等同**：KOSPI 早盘高 beta 易超调，A 股通常有政策/维稳缓冲，**跌幅往往小于韩国**。
- **任何时点都可判断，按当下信息尽力分析并持续更新**：不必等到韩国定盘才下结论——每个时点都应用**当下可得的全部信息**尽力判断，接受「不一定完全准确」。盘中信号（反弹/回落）标为**暂定**、权重低；随韩国尾盘、美债/美元/黄金/纳指期货等新信息**持续更新**。韩国收盘（北京 14:30）是**加权验证**，不是判断的前置条件。
- **趋势 > 跳动**：任何单一市场的盘中反弹，都不足以推翻**美债 / 美元 / 黄金 / 纳指期货的全天趋势**。若纳指期货全天持续走弱，A 股科技即便盘中反抽，也大概率收在低位。
- **regime 决定先验**：在鹰派 regime（10Y ≥ 4.82%、加息概率高企、油价破百）下，情景概率须向**「走弱 / 深调」倾斜**，不要沿用中性分布。
- **锚与跨腿冲突时，以当下定价为准（2026-09-15 定案）**：量化锚给的是「SOX **单因子**条件分布」，其样本期多处在**外部趋势向下**的环境里。当**韩国 / 纳指期货 / A50 / 汇率**这些腿**同时反向**时，必须**用当下定价覆盖锚**，并把「冲突」本身写进结论——**不得锚与主观悲观二选一、取更悲观的那个**。案例：2026-09-15 锚给科创50 跳空中位 **-0.12%**（实际 **-0.26%**，锚是对的），我手工放大到 -1%~-2% 并照搬锚的「盘内再跌 -0.95%」，结果科创50 收 **+1.55%**、半导体ETF +1.80%。
- **量化锚（2026-09-15 新增）**：费半（SOX）与**次日**科创50 的相关系数仅 **0.119**、β = **0.111**（半导体ETF β = 0.13；672 个交易日，2023-10-31 ~ 2026-09-11）。**费半单日 ≤ −5% 的 19 次样本**：科创50 次日均值 −1.10%、上涨占比 42%、**平均跳空仅 −0.53%，但开盘→收盘再跌 −1.02%** → 形态是**「低开不多、盘中阴跌」**：别指望一步到位，也别因为开盘只跌 1% 就判定无事。**反直觉**：费半 5 日累计 ≤ −8% 时次日反而中性偏多（n = 35，中位 +0.17%）——先判断是「单日重击」还是「连续崩塌」，两者次日行为不同。

## 5. 失效边界（用之前必须先查）

- **成分不同**：韩国是**纯全球存储周期**；A 股半导体含**国产替代**独立逻辑——外部封锁/减速反而可能被政策强化（如数字绿色协同转型方案）。**韩国跌，A 股「国产算力」未必同跌**。
- **（2026-09-15 补）这条边界必须给权重，不能只「提一句」**：当天康宁 -13.7%、Coherent -12.7% 只传导到 A 股光模块（-1%），而**国产算力（寒武纪 +3.44%、中芯 +0.69%）与 PCB/材料反手大涨**。**情景构建规则：凡已记录的失效边界有可能被触发，必须在情景表里单列一格**（如「海外链杀跌、国产链独立走强」），不能只给「跌 / 不跌」两态。
- **资金结构不同**：韩国跌常是**外资卖**；A 股是散户+政策+北向，常有维稳/政策缓冲。
- **适用对象有限**：只对**半导体/存储/设备/算力硬件**参考价值高；对**内需/军工/红利/国产替代主题**几乎无用。
- **不可外推到指数**：该因子用于判断**科技板块开盘偏向**，**不能**用它预测整个上证/沪深300方向。
- **单一锚警告**：韩国只是「芯片 beta 的最近读数」，不是 A 股的因果驱动。定方向仍要回到「美债实际利率 + 政策 + 资金」这三个主轴。

## 6. 标杆案例：2026-09-14（纳入该因子的触发事件）

- **美股周五（9-11）收涨**：道指 +0.98%、纳指 +0.96%、标普 +0.86%、费半 +1.81%。
- **韩国早盘反向大跌**：KOSPI **−2.88%**、KOSDAQ −1.47%，**三星 −3.5%、SK海力士 −5.2%** 领跌，外资+机构卖出（3 个交易日连续下跌）。
- **驱动**：① **中东局势**（油价 102.8，霍尔木兹风险）；② **「AI 减速论」**（AI 资本开支放缓担忧）。
- **印证**：纳指期货 −1.21%、标普期货 −0.47%，科技领跌——三方共振指向同一方向。
- **结论/教训**：A 股半导体/算力**低开概率高**，当日「修复式反弹」判断被**降级**；「AI 减速」叙事直接压制 A 股 AI 算力主线。
- **方法论沉淀**：当**亚洲早盘背离美股收盘**时，亚洲定价的是**前瞻风险**，此时韩国信号价值最高——这正是把该因子制度化的原因。
- **当日实际结果（收盘复盘）**：韩国**收在全天最低附近，KOSPI −3.26%**（高 6773.97 / 低 6654.82 / 收 6684.37）——**早盘 10:00 从 −2.88% 收窄到 −2.17% 的反弹是假信号**，午后再度走弱。A 股：上证 −0.07%（横盘）、创业板 −1.10%、科创50 −1.62%、半导体ETF −1.35%（最低 0.935、守住）。港股逆势收红（HSI +0.45%）。
- **三条修正教训（2026-09-14 复盘）**：① **盘中反弹 ≠ 企稳**，采信以韩国**收盘**为准；② **外部趋势才是主线**——纳指期货全天从 −1.07% 恶化到 **−1.81%**、黄金 −2%、美元升破 99.5，单一市场盘中反弹是噪音；③ **A/H 分化**——南下资金**连续 10 日净卖出中芯国际**，A 股半导体有结构性逆风，港股强弱不能简单外推到 A 股。

## 7. 输出要求（**融入整体评估，不单列**）

韩国因子**不单独成节、不做独立结论**——它是整体判断里的**一个权重项**。理由有两条：单列会把它抬成「单一锚」，违反身份文档元规则 1；而它按定义只对半导体/存储/算力/科创50 这些**同因子板块**有效，对指数方向的解释力有限。它最大的价值是**修正幅度与概率**，不是**决定方向**。

融合时，以下四项必须**用一句话写进对应判断的论证里**（可追溯，但不另起小节）：

1. **方向与幅度**：KOSPI / KOSDAQ 涨跌幅、是否跳空；三星与 SK海力士**是否同向**（同向=板块性，单边=个股性）；
2. **是否背离**：与美股收盘、纳指期货同向还是背离——背离时以韩国/期货为准（它们在定价当下，美股收盘是过去时）；
3. **映射到哪**：只映射到**半导体 / 存储 / 算力 / 科创50 的开盘偏向**，**不外推到上证/沪深300**；
4. **失效边界**：本次是否触发「成分 / 资金 / 适用对象」哪一条。

**写法对照**：

> ❌ 不这样写——**独立小节、数据单列成结论**：
> 「【韩国因子】KOSPI 开 -0.38%，早盘翻红至 +0.03%，KOSDAQ +1.15%，三星与海力士平盘……」

> ✅ 这样写——**融进幅度与概率的论证里**：
> 「低开幅度会比按费半 -5.9% 机械外推的更浅——韩国今早没跟跌（KOSPI 从 -0.38% 翻红、KOSDAQ +1.15%、三星与海力士平盘），说明这次是**硬件链在杀、不是亚洲科技情绪在崩**；但这条只用来**收窄幅度预期、上调上行概率**，不用来定方向：韩国是外资主导、只对半导体同因子有效，且它此刻的翻红仍属盘中跳动。」

**权重原则**：韩国因子在早盘结论里**最多修正幅度与概率，不得单独充当方向依据**；方向仍由「美债实际利率 + 政策 + 资金」三主轴与指数自身技术位决定（见身份文档 §10 场景速查表的「不可外推」提醒）。
